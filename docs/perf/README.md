# 성능·안정성 개선 로그

"측정 → 원인 분석 → 개선"의 전체 사이클을 기록합니다.
수치 없는 개선 주장은 기록하지 않습니다.

## 작성 형식

파일명: `NNN-개선-대상.md`

```markdown
# NNN. 제목 (예: 자막 스트림 수신 시 전체 리스트 리렌더 제거)

## 증상 / 문제
사용자 관점에서 무엇이 느리거나 불안정했는가

## 측정
- 도구: (Lighthouse, React DevTools Profiler, Chrome Performance, WebPageTest 등)
- 조건: (기기, 네트워크 스로틀링, 데이터 규모)
- 수치: 개선 전 값

## 원인 분석
측정 데이터에서 병목을 특정한 과정. 추측이 아닌 프로파일 근거로.

## 개선
적용한 변경과 그 원리. 커밋/PR 링크.

## 결과
동일 조건 재측정 수치. before → after.

## 회귀 방지
(해당 시) 성능 예산, CI 체크, 테스트 등
```
