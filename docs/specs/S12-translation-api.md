# S12. 번역 API 연동 — 자유 텍스트 실번역

- **갈래**: 기능 · **의존**: 없음 (S05와 시너지) · **판정**: 대기 · **관련**: F02

## 배경

대화 번역이 사전 매칭 + `[demo]` 폴백(`translate.ts`)이라, 퀵 리플라이(S05) 밖의 자유
텍스트는 번역 품질이 데모 수준에 그친다. 간단한 무료 번역 API를 붙이면 자유 대화도
실번역이 된다.

## API 선택

- **채택 제안: Azure Translator F0** — 월 200만 자 상시 무료(기간 제한 없음), ko/en/ja/zh
  지원, REST 단순. Azure 계정+카드 필요.
- 검토·탈락: DeepL API Free — 2026년 중반부터 신규 가입 중단(기존 가입자만 유지), 신규는
  Developer 플랜(총 100만 자 소진형). Google Cloud Translation — 무료 50만 자/월로 Azure의
  1/4. MyMemory — 가입 불필요하나 품질 불안정, **키 미설정 시 폴백 후보**로만 언급.

## 명세

### 서버 (`apps/mock-server`) — 3단 번역 파이프라인

`translate.ts`를 다음 순서의 폴백 체인으로 재구성한다:

1. **사전 매칭** — 퀵 리플라이·정형 문구(S05, i18n 단일 원천). 무비용·결정적이라 최우선.
2. **Azure Translator 호출** — `AZURE_TRANSLATOR_KEY` 환경변수가 있을 때만. 타임아웃 3s.
3. **`[demo]` 폴백** — 키 없음/호출 실패 시 기존 동작. **저장소 클론만으로 실행 가능**
   조건을 유지한다(키는 선택 사항).

- **캐시**: (원문, 대상 언어) → 번역 LRU 캐시(상한 1,000건) — 무료 한도 절약 + 반복 문장
  즉답.
- 키는 서버에만 둔다(클라이언트 노출 금지). 호출 실패는 로그만 남기고 대화 흐름을 막지
  않는다(무음 실패 금지 — 폴백 결과에 폴백임이 드러나므로 무음 아님).
- Symposia 자막 번역은 **스크립트 내장 번역 유지** — 데모 결정성(같은 강연을 항상 같은
  품질로 재생)이 API 실번역보다 중요. 대화(CareTalk)만 API 대상.

## 완성 기준

1. 키 설정 시: 사전에 없는 자유 문장에 `[demo]` 마커 없이 실번역이 붙는다.
2. 키 미설정 시: 현재와 동일하게 동작한다(회귀 없음).
3. API 장애 시: 3s 내 폴백으로 대화가 지연 없이 계속된다.
4. 동일 문장 반복 시 API 재호출이 없다(캐시).

## 테스트

- 유닛: 폴백 체인 — 사전 히트 시 API 미호출 / 키 없음 → `[demo]` / API 실패(mock) → `[demo]`.
- 유닛: LRU 캐시 — 히트 시 API 미호출, 상한 초과 시 오래된 항목 축출.
- 통합: Azure 호출부는 mock으로 계약(요청 형식/응답 파싱)만 검증 — 실키 테스트는 수동.
- 수동: 실키로 ko↔en 자유 문장 왕복 1회 확인(스모크).

## 작업 분해

1. translate.ts 폴백 체인 + 캐시
2. Azure 클라이언트(fetch, 타임아웃, 에러 매핑)
3. 테스트(유닛/mock 통합)
4. 배포(S07)에 환경변수 추가 + README 문서화

## 구현 노트 (명세와 달라진 점)

구현: `apps/mock-server/src/{translate,azure-translator}.ts` ·
설계 배경 [ADR 0007](../adr/0007-translation-fallback-chain.md) ·
운영 문서 [apps/mock-server/README.md](../../apps/mock-server/README.md)

- **캐시 키에 출발 언어를 포함**한다. 명세는 (원문, 대상 언어)지만 출발 언어가 다르면 결과도
  달라지므로 (출발 언어, 대상 언어, 원문)을 키로 쓴다. 상한 1,000건은 그대로.
- **Azure 성공 결과만 캐시**한다. 실패를 캐시하면 장애가 복구돼도 폴백이 굳어 버린다.
- **환경변수를 3개 추가**했다 — `AZURE_TRANSLATOR_REGION`(지역 전용 리소스용 헤더),
  `AZURE_TRANSLATOR_ENDPOINT`(전용 엔드포인트), `AZURE_TRANSLATOR_TIMEOUT_MS`(기본 3000).
  모두 선택 사항이고, 키가 없으면 어느 것도 읽지 않는다.
- **연속 실패 차단기를 추가**했다(명세에 없던 항목). 3회 연속 실패 시 30초간 2단계를 건너뛴다.
  없으면 API 장애 때 메시지마다 3초씩 지연돼 완성 기준 3("지연 없이 계속")을 만족하지 못한다.
- **앱의 `zh`는 Azure 요청 시 `zh-Hans`로 변환**한다. Azure가 간체/번체를 구분하기 때문.
- **호출부 이관은 미완**이다. `translate.ts`는 기존 동기 `mockTranslate`(사전+`[demo]`)를
  유지한 채 비동기 `translateText`/`translateConversation`을 추가했다. `conversation.ts`가
  아직 동기 `mockTranslate`를 호출하므로, **그 호출부가 `await translateText(...)`로 옮기기
  전까지 2단계(Azure)는 실제로 켜지지 않는다.** 완성 기준 1은 이 이관 후 충족된다.
- 사전은 아직 `translate.ts` 안의 표다. S05(정형 문구)가 들어오면 `packages/i18n`을 단일
  원천으로 삼아 대체한다.
