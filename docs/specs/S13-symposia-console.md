# S13. Symposia 운영 콘솔 — 간사·발표자 기능

- **갈래**: 구조 · **의존**: S01–S03 (라우팅), F01 · **판정**: 대기

## 배경 (F01 근거)

현재 Symposia에는 참가자 기능만 있다. 세션은 서버 부팅 시 자동 재생되고, 간사(세션
생성·코드 발급·시작/종료)와 발표자(발화 제어·자막 모니터)의 자리가 없다 — 학회를
"운영"하는 쪽 여정이 통째로 빠져 있다. F01의 간사·발표자 기능을 하나의 운영 콘솔로
구현한다(데모 판단: 별도 발표자 화면 대신 콘솔에 통합).

## 명세

### 서버 — 세션 라이프사이클 API

- 부팅 시 자동 `broadcaster.start()`를 제거하고 콘솔 제어로 전환:
  - `POST /api/sessions` → 세션 생성 `{ title, speaker, sourceLang, targetLangs }` —
    자막 소스는 데모 스크립트(keynote) 템플릿을 복제.
  - `POST /api/sessions/:id/start | pause | resume | end` — 상태 전이. `end` 시
    `session-ended` 브로드캐스트(프로토콜에 이미 존재).
  - `GET /api/sessions/:id/status` → `{ state, viewerCount, position }`.
  - 재생 제어: `POST /api/sessions/:id/rate { rate: 0.5–2 }` — 발표자 속도 제어의 데모 대체.
- 기존 `GET /api/sessions`는 `state` 필드를 추가해 유지(참가자 로비·콘솔 공용).

### 클라이언트 — 콘솔 화면 (`/console`, S03 라우팅)

- **세션 목록**: 상태 배지(대기/재생/일시정지/종료) + 시청자 수.
- **세션 생성 폼**: 제목·발표자·언어 선택(템플릿 기반).
- **세션 상세(운영)**: 입장 코드·QR(S03 URL), 시작/일시정지/재개/종료 버튼,
  재생 속도 컨트롤, **자막 모니터**(참가자와 동일한 스트림을 구독하는 미리보기 —
  기존 자막 컴포넌트 재사용).
- 참가자 화면: `session-ended` 수신 시 "세션이 종료되었습니다" 안내 + 홈 복귀 버튼
  (현재는 이벤트만 있고 화면 처리 없음 — 여기서 마감).
- 인증 없음(데모 한계, F01에 문서화) — 콘솔은 URL로만 진입.

## 완성 기준

1. 콘솔에서 세션을 만들고 시작하면, 참가자가 코드/QR로 입장해 자막을 본다(참가자 자동
   재생 의존 제거).
2. 일시정지/재개/속도 변경이 시청 중인 참가자 화면에 즉시 반영된다.
3. 종료 시 참가자 화면에 종료 안내가 뜬다.
4. 자막 모니터가 참가자와 같은 내용을 보여준다.

## 테스트

- 유닛(서버): 상태 전이 — 허용/불허 전이(대기→재생→일시정지→재생→종료, 종료 후 조작 거부),
  rate 경계값(0.5/2 밖 거부).
- 통합(서버): start 후 SSE 구독 시 자막 흐름, pause 중 이벤트 미발행, end 시
  `session-ended` 수신.
- 유닛(클라): 콘솔 상태 스토어 — status 폴링 반영, 버튼 활성화 조건.
- 수동: 콘솔+참가자 2탭 시나리오(완성 기준 1–4 재현).

## 작업 분해

1. 서버 세션 상태 머신 + API
2. 콘솔 화면(목록/생성/상세)
3. 자막 모니터(기존 컴포넌트 재사용)
4. 참가자 종료 안내 처리
5. 테스트

## 범위 제외

발표자 별도 화면, 실제 STT 입력, 다중 간사 동시 편집, 세션 일정표.
