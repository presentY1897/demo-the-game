# S02. 역할 기반 진입 동선과 온보딩

- **갈래**: 구조 · **의존**: S01 · **판정**: 대기

## 배경 (진단 근거)

첫 화면(HomeScreen)이 회사 소개 + 기능 목록의 **데모 로비**다. 실제 사용자 여정
(참석자: 코드/QR로 세션 입장, 환자: 초대 코드로 방 입장, 의료진: 방 개설)이 없고,
CareTalk 진입 시 역할·언어 선택 없이 환자/영어로 하드코딩된다.

## 명세

### 홈 화면 재편

- 로비를 실사용 분기 2개로 재편:
  - **Symposia** — "세션 코드로 입장" 입력 + 진행 중 세션 목록(참석자 관점: 제목·발표자·
    언어쌍·LIVE 표시. 기존 TanStack Query 로직 재사용).
  - **CareTalk** — "새 대화 시작"(의료진) / "초대 코드로 입장"(환자) 두 버튼.
- 회사 소개·데모 안내 문구는 별도 "정보" 시트(또는 product 홈페이지 링크)로 이동 —
  첫 화면에서 제거.

### CareTalk 온보딩

- 진입 시 1스텝 온보딩: 역할은 진입 버튼으로 이미 결정 → **언어 선택**만 남긴다.
  - 환자: en/ja/zh 등 — S14 채택 시 기관 지원 언어 설정을 따르고, 그전엔 i18n 리소스 기준.
    의료진: ko 기본(변경 가능).
- 선택 결과는 `conversationStore`에 저장하고 `useConversation(roomId, role, lang)`에 주입
  — `('patient', 'en')` 하드코딩 제거.

### Symposia 입장

- 세션 코드 = 목 서버의 세션 id(`keynote-01`)를 그대로 코드로 취급(별도 발급 없음).
  잘못된 코드는 스트림 404 → 인라인 에러.
- 자막 언어 선택(기존 칩)은 화면 유지 — 온보딩으로 옮기지 않는다(시청 중 전환이 실사용).

## 완성 기준

1. 첫 화면에서 세 여정(참석자/의료진/환자)이 각각 3탭 이내로 목적 화면에 도달한다.
2. 하드코딩된 역할·언어가 코드베이스에서 사라진다.
3. ko/en UI 언어 전환(기존 헤더 기능)이 재편 후에도 동작한다.

## 테스트

- 유닛: 온보딩 스토어 — 역할/언어 저장·reset, 세션 코드 검증 유틸(빈 값/미지 코드).
- 유닛: 환자 언어 목록이 기관 설정(S14)을 따르는 셀렉터.
- 자동화는 스토어/유틸 로직 단위까지 — RN 컴포넌트 렌더 테스트는 범위 외(S10 정책).
- 수동: 세 여정(참가자/의사/환자) 3탭 도달 체크리스트, ko/en UI 전환 후 온보딩 문자열 확인.

## 작업 분해

1. 홈 화면 분기 UI 재구성 (기존 세션 목록 로직 이전)
2. CareTalk 언어 선택 온보딩 + store 연결
3. 세션 코드 입력 + 에러 처리
4. 정보 시트 분리
5. i18n 문자열 추가 (ko/en)

## 범위 제외

계정/프로필, 온보딩 다시 보기 설정, Symposia 세션 코드 발급 체계(목 세션 id 겸용으로 충분).

## 구현 메모 (2026-09-01)

- **홈은 카드 2장 + 정보 링크**로 끝난다. 회사 소개·미션·데모 안내는 `InfoSheet`
  (하단 모달)로 옮겼고, 첫 화면에는 "무엇을 하러 왔는가"만 남겼다.
- **세션 코드 검증은 목록 대조로 한다** (`src/session/code.ts`). 세션 코드 = 목 서버의
  세션 id라 별도 발급 체계가 없고, 열린 세션 목록(TanStack Query가 이미 받아 둔 것)에
  있는지로 판정한다 — 스트림을 열어 404를 받기 전에 인라인 에러를 띄울 수 있다.
  빈 값과 미지 코드를 다른 문구로 구분한다(`empty` / `unknown`).
- **환자 언어 목록의 정본은 기관 설정**(`GET /api/admin/settings`의 `patientLangs`).
  조회 실패 시에만 i18n `language` 리소스 기준 폴백(`ko` 제외)으로 떨어진다.
  **읽는 동안에는 목록을 그리지 않는다** — 폴백을 먼저 보여주면 설정이 도착하는 순간
  손가락 밑에서 목록이 바뀐다.
- **의료진 언어도 고를 수 있다.** 기본 `ko`, 후보는 `['ko', ...supportedLangs]`
  (F02의 코디네이터 사례). 명세의 "ko 기본(변경 가능)"을 그대로 구현한 것.
- **온보딩 스토어에 `confirmed` 플래그를 뒀다.** 역할을 고르면 기본 언어가 미리 놓이는데,
  값이 있다는 것과 사용자가 확인했다는 것은 다르다 — 확인 전까지 언어 단계가 유지된다.
- **역할 선택 화면(`RoleStep`)이 하나 더 있다.** 홈의 두 버튼이 역할을 정하므로 평소에는
  안 보이고, `/room`(코드 없는 경로)으로 직접 들어와 역할을 알 수 없을 때만 나온다.

### 실제 탭 수 (완성 기준 1)

| 여정 | 탭 |
|---|---|
| 참가자 | 세션 행 탭 **1** (코드 입력 경로도 입력 후 "입장" 1탭) |
| 의료진 | "새 대화 시작" → "계속"(언어 확인) = **2** → 코드·QR 대기 화면 |
| 환자 | "초대 코드로 입장" → "계속" → 코드 입력 후 "입장" = **3** (QR/링크 진입은 **1**) |
