# F01. 기능 명세 — Symposia (학회 실시간 자막)

- **층위**: 기능 명세(F) — 사용자 집단을 먼저 정의하고 역할별 기능을 설계한다.
  작업 명세(S)는 이 문서의 기능을 구현 단위로 쪼갠 것이다.

## 사용자 집단

| 역할 | 정의 | 사용 맥락 | 핵심 목표 |
|---|---|---|---|
| **간사** (운영진) | 학회 사무국·세션 운영 담당 | 행사 전 준비, 행사 중 운영석/백스테이지 | 세션을 만들고 참석자를 입장시키고 문제 없이 굴러가게 |
| **발표자** | 강연하는 의사/연자 | 무대 위, 발표 중 | 내 발표가 자막으로 제대로 전달되는지 |
| **참가자** | 국내외 참석 의사·업계 관계자 | 어두운 강연장, 폰, 30–60분 시청 | 내 언어로 놓치지 않고 자막을 따라가기 |

## 역할별 기능 설계

### 간사 (운영)

| 기능 | 설명 | 데모 구현 | 작업 |
|---|---|---|---|
| 세션 생성·편집 | 제목·발표자·원문 언어·제공 언어 등록 | ✅ 콘솔에서 생성(스크립트 템플릿 기반) | S13 |
| 입장 코드·QR 발급 | 세션별 코드/QR을 발급해 장내 게시 | ✅ | S13 (QR은 S03) |
| 세션 시작·일시정지·종료 | 라이프사이클 제어 (현재는 서버 부팅 시 자동 재생 — 이를 콘솔 제어로 전환) | ✅ | S13 |
| 진행 모니터링 | 접속자 수·스트림 상태 확인 | ✅ 최소(카운트+상태 배지) | S13 |
| 프로그램/트랙 관리, 발표자 계정 초대 | 다세션 행사 운영 | ❌ 실서비스 영역 | — |

### 발표자

| 기능 | 설명 | 데모 구현 | 작업 |
|---|---|---|---|
| 발화 입력 | 실서비스는 마이크 STT. 데모는 **스크립트 재생 제어(재생/일시정지/속도)** 로 대체 | ✅ 콘솔에 통합 | S13 |
| 자막 모니터 | 내 발화가 자막·번역으로 어떻게 나가는지 실시간 확인 | ✅ 콘솔 내 미리보기(참가자 뷰와 동일 스트림) | S13 |
| 자막 정정 요청, 발표자료 연동 | | ❌ 실서비스 영역 | — |

데모 범위 판단: 발표자 전용 화면을 따로 만들지 않고 **운영 콘솔에 재생 제어·모니터로
통합**한다(1인 시연에서 간사·발표자를 오가며 보여주는 게 자연스러움). 분리가 필요하면
S13에서 재판단.

### 참가자

| 기능 | 설명 | 데모 구현 | 작업 |
|---|---|---|---|
| 코드/QR 입장 | 로비 없이 세션 직행 | ✅ | S02, S03 |
| 자막 언어 선택 | 시청 중 전환 가능 | ✅ 구현됨 (언어 칩) | — |
| 실시간 자막 시청 | 부분(▌)→확정→번역, 자동 스크롤 일시정지/재개 | ✅ 구현됨 | — |
| 재연결 복구 | 끊겨도 놓친 확정 자막 복구 | ✅ 구현됨 (Last-Event-ID) | — |
| 스테이지 모드 | 어두운 강연장용 다크+대형 자막+화면 꺼짐 방지 | ✅ | S04 |
| 가독성·접근성 | 폰트 조절(구현됨), 대비/라벨/폰트 스케일 | ✅ | S06 |
| 질문 제출·세션 피드백 | | ❌ 실서비스 영역 | — |

## 도메인 흐름 (역할 간 상호작용)

```
간사: 세션 생성 → 코드/QR 게시 → 시작
발표자: (데모: 재생 제어) 발화 → 자막 파이프라인 → 모니터로 확인
참가자: QR 입장 → 언어 선택 → 시청 (스테이지 모드) → 세션 종료 시 안내
```

세션 종료 시 참가자 화면은 `session-ended` 이벤트로 종료 안내를 표시한다(프로토콜에
이미 존재 — 화면 처리는 S13에서 함께).

## 데모 범위 원칙

- 1인 개발·시연 전제: 운영 기능은 "동작하는 최소"로, 실서비스 전용(계정·행사 관리)은
  명시적으로 제외하고 표에 ❌로 남긴다 — 리뷰어가 "생각은 했고 범위를 잘랐다"를 볼 수 있게.
- 역할 구분에 인증은 두지 않는다(콘솔은 URL로 진입) — 데모 한계로 문서화.
