# S04. Symposia 스테이지 모드

- **갈래**: UX · **의존**: 없음 (S02와 병행 가능) · **판정**: 대기

## 배경 (진단 근거)

Symposia의 실제 사용 맥락은 **어두운 강연장에서 폰으로 30–60분 시청**이다. 그런데
`theme.ts`가 `semanticColor.light` 고정이라 다크 모드가 없고(tokens의 다크 세트는
정의만 있고 미사용), 화면 꺼짐 방지가 없어 몇 분이면 자막이 꺼진다.

## 명세

### 테마 전환 기반

- `theme.ts`의 정적 객체를 테마 컨텍스트(light/dark)로 교체 — `semanticColor[mode]` 소비.
  기존 화면의 `color.*` 참조는 훅(`useTheme()`) 경유로 전환.
- 시스템 다크 설정(`useColorScheme`)을 기본값으로 따르되, 스테이지 모드는 강제 다크.

### 스테이지 모드 (자막 화면 토글)

- 토글 ON 시:
  - 다크 테마 강제 + 상태바 어둡게.
  - **최신 확정 자막 1건 + 진행 중 부분 자막**만 대형 타이포로 표시(히스토리 리스트 숨김).
    번역 병기 유지, 폰트 조절(A−/A＋)은 스테이지 모드에서도 동작.
  - `expo-keep-awake` 활성 — 시청 중 화면이 꺼지지 않는다. OFF/화면 이탈 시 해제.
- 토글 OFF 시 기존 히스토리 리스트 뷰로 복귀(스크롤 위치·데이터 보존 — 스토어는 그대로,
  뷰만 전환).

### 대비 기준

- 다크 팔레트의 자막 텍스트/배경 대비는 WCAG AA(4.5:1) 이상 — S06의 대비 검사 스크립트로
  검증(토큰 값 조정이 필요하면 tokens에서 수정).

## 완성 기준

1. 스테이지 모드 토글 왕복 시 데이터 손실 없이 뷰가 전환된다.
2. 스테이지 모드 중 화면이 자동으로 꺼지지 않는다(keep-awake 활성 확인).
3. 다크 상태에서 자막 대비 AA 충족.
4. 시스템 다크 설정 시 앱 전체가 다크로 뜬다.

## 테스트

- 유닛: 테마 컨텍스트 — 모드별 토큰 매핑, 시스템 다크 추종, 스테이지 모드 강제 다크 우선.
- 유닛: 스테이지 뷰 셀렉터 — "최신 확정 1건 + 진행 중 부분 자막"만 선택됨(스토어 레벨).
- 자동(대비): 다크 팔레트 AA는 S06의 tokens 대비 테스트가 커버.
- 수동: 토글 왕복 시 데이터·스크롤 보존, 화면 자동 잠금을 30초로 설정하고 keep-awake 확인,
  스테이지 모드 중 폰트 조절 동작.

## 작업 분해

1. 테마 컨텍스트 도입 + 기존 화면 마이그레이션
2. 스테이지 모드 뷰(대형 자막) + 토글
3. expo-keep-awake 연동 (설치 필요)
4. 다크 대비 확인·토큰 조정

## 범위 제외

수동 라이트/다크 설정 화면(시스템 추종 + 스테이지 강제 다크로 충분), product 홈페이지
다크 모드(별도 판단), 가로 모드 전용 레이아웃.
